4. Payment Gateway Technology

Status: Working on

Supported Payment Types

  • In-App Purchases (Coins system)
  • Subscriptions (Premium plans)

Technologies Used

  • Google Play Billing Library
    • In-App Products (INAPP)
    • Subscriptions (SUBS)

Flow

  1. User selects coin/package
  2. Google Play purchase initiated
  3. Purchase verified
  4. Coins credited via backend
  5. UI updated with new balance

Backend Requirements

  • Purchase token validation
  • Secure transaction verification
  • Coin balance management

5. User Registration & Login

Registration Flow

  1. User enters:
    • Phone
    • Password
  2. API Request sent to backend:
{
 "number": "1234567890",
 "password": "******"
}
  1. Backend Response:
    • Success → User created
    • Failure → Error message
  2. On Success:
    • Store token locally
    • Navigate to Dashboard

Login Flow

  1. User enters:
    • Phone
    • Password
  2. API Request sent to backend:
{
 "number": "1234567890",
 "password": "******"
}
  1. Backend Response:
    • Success → User created
    • Failure → Error message
  2. On Success:
    • Store token locally & Navigate to Dashboard

Authentication

  • Token-based authentication (JWT or similar)
  • Token stored securely (SharedPreferences)

Validation Rules

  • Mobile number format validation
  • Password strength check
  • Required field validation
